Online Store Webpage

Status : Completed


During my second year at MTU, I worked in a two man team to develop a small web application to create an online store for a supermarket.

This application performed basic functions of an online store web page, allowing users to create accounts, browse products, add products to their cart, and checkout.

We also developed a admin panel for the store, allowing employees to add and remove products, update information like price and quantity, and view order history using the customers account information.

Even though this project didn't demonstrate refinement and quality of how the page looked, it taught me a lot about the functionality of web applications and how to manage and protect user data.

This project was developed using HTML, PHP, and SQL, deployed on a local server that was provided by MTU.
